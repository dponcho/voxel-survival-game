## Correction and measurement boundary

The new preparation-demand mode records each sequence-prefix.json publication
as common batch work after the completed trial and terminal marker. Its witness
retains the completed-trial identity/count, monotonic wall interval, actual JSON
write result/error and missing/unavailable/retained file state. Readable retained
bytes have an exact size and SHA-256; missing/unavailable bytes stay null.

A publication failure stops the batch, truncates the inherited scenario list,
refuses direct later entry to trial setup and forces a failed batch outcome.
An already failed trial keeps its earlier stop reason. Its immutable complete/
terminal snapshots, hashes, original trial I/O flag, validity and counter
boundaries are preserved. A valid trial can therefore remain valid while the
later batch publication is explicitly invalid.

The independent reader checks publication order and chronology, raw write
errors, the exact last retained file and successful prefix contents. It rejects
any later complete or partial trial after failed publication. An honest early
stop after a valid trial is allowed only with a verified failed publication.
Stale, truncated or empty failed output remains failed evidence, never a current
successful prefix. If no trial completed, no publication is invented. Complete
trial work/cost checks and the old v1/v2 readers/verdicts remain unchanged.

with a five-second fixture cap and sixty-second outer timeout. It uses synthetic
completed-trial data, the production publication/writer/start guard, and the
actual inherited drain/handover. World setup is a counted seam; probe snapshots
must show no new terrain work or active observer. It is not a shortened route.

The paired before fixture executes the exact frozen rejected tail from the
saved source witness. A real failed FileAccess open must reproduce one next
setup dispatch. Seven fixed controls cover normal handover, failure after the
warm-up/middle/last trial, an already invalid trial, ordinary final termination,
and an invalid trial followed by a publication failure. Failures must dispatch
zero next setups, including a direct entry attempt after the stop. This proves
recorder/terrain setup is not reached. Immutable synthetic complete/terminal
files and original trial flags must remain identical.

The reader independently audits these controller reports, retained files,
raw open errors, native snapshots and twelve saved corruptions. Twelve new pure

immutable work flags, re-signed bad contents and boundary chronology.
